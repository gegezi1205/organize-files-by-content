通用文件智能整理 Skill｜通用 Agent 安装包

版本：1.5.0

本包不默认任何具体 Agent。只有能够安装或发现本地 Skill，并获得用户授权访问本地文件的 Agent，才可以执行整理。

使用顺序：

1. 把整个安装包文件夹或 ZIP 放到使用者桌面；如使用 ZIP，先完整解压。
2. 将“01_只安装Skill_提示词.txt”完整发送给当前 Agent。
3. 等 Agent 明确报告“Skill 已被实际发现、中文名称和详细简介已生效、Skills 归类已完成、安全自测通过”后停止。
4. 再将“02_安装完成后_选择范围并整理到桌面_提示词.txt”完整发送给 Agent。
5. 第二阶段必须先用短选项确认整理来源、桌面目标和操作权限；只让使用者自由填写职业、职位等必要身份和无法检测的自定义路径，其余画像元素均由 Agent 提供选项。首轮工作类型候选输出后必须停止。
6. 使用者明确回复后才可继续；“暂不确定，待盘点后再问”只授权只读盘点。Agent 完成只读盘点后须再次用真实文件证据校正画像，展示全量预览并获得明确确认；暂缓项和待选择项清空后才可移动、改名或处理普通重复。

关键边界：

- 安装阶段不得读取、扫描或整理任何真实文件。
- 执行阶段只处理使用者逐项确认的文件夹和文件，不得扩大到整台电脑或未经确认的相邻目录。
- 职业、职责、业务对象、交付物、接收方、周期、协作关系、原目录和正文内容都是判断元素，不是目录模板；职业候选必须由本人确认。
- 最终目标位置是使用者确认的真实桌面路径。所有授权来源中的可处理文件归入桌面上的正式分类结构，不散铺在桌面。
- 内置脚本每次只处理一个授权根目录。多个电脑位置统一迁移到桌面时，由当前 Agent 按已确认的全量预览逐项执行和验收；根目录外文件不能静默跳过。
- 歧义、不可读、加密、损坏、仅云端占位、同步中、下载中、权限不足或正在使用的项目保持原位，并明确列入待确认或阻塞。
- 压缩包会在明确授权后安全解压并逐文件识别；文字图片只有方向识别优势明确时才纠正。普通文件仍逐个按内容自动命名归位。
- 安装 Skill 不等于启用后台监控。本包不授权创建投放箱、登录自启动、定时任务或后台监控；这些状态须另行确认，并在一次真实投递验证通过后才可安装自启动。

安装包结构：

- organize-files-by-content/：Skill 主体
- SKILL_INTRO.txt：建议中文显示名称、详细中文简介和归类依据
- 01_只安装Skill_提示词.txt：只安装、适配当前 Agent、设置中文元数据、完成 Skills 归类和验证
- 02_安装完成后_选择范围并整理到桌面_提示词.txt：确认来源与身份画像后，再预览和执行
